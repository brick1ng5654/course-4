# course-4

## Дисциплины

- Организация процессов и программирование в среде Linux
- Безопасность жизнедеятельности
- Защита компьютерной информации
- Языки проектирования аппаратуры

## Организация процессов и программирование в среде Linux

Темы лабораторных работ:

1. Установка и настройка ОС Ubuntu
2. Управление пользователями и мониторинг работы ОС Ubuntu
3. Создание и идентификация процессов
4. Управление потоками
5. Обработка сигналов
6. Организация периодических процессов
7. Обмен данными через канал
8. Взаимодействие процессов на основе сообщений
9. Обмен данными через разделяемую память
10. Синхронизация процессов с помощью семафоров
11. Взаимодействие процессов через сокеты

## Безопасность жизнедеятельности

Темы лабораторных работ:

1. Исследование условий электробезопасности в трёхфазных сетях с изолированной и с компенсированной нейтралями
2. Исследование электромагнитного поля микроволновой печи и защитных экранов
3. Эффективность и качество освещения
4. Исследование параметров производственного шума и определение эффективности мероприятий по защите от него
5. Защита от ультрафиолетового излучения

## Защита компьютерной информации

Темы лабораторных работ:

1. Управление доступом к файловой системе NTFS с помощью списков контроля доступа
2. Работа с Active Directory:

   - Часть 1. Аутентификация пользователей. Каталоги сетевых ресурсов. Active Directory
   - Часть 2. Групповые политики Active Directory

3. Работа с сертификатами PKI без Active Directory

## Языки проектирования аппаратуры

Темы лабораторных работ:

1. Структура программы на VerilogHDL
2. Представление комбинационных схем и простых триггерных устройств
3. Модульное и иерархическое проектирование
4. Описание цифровых автоматов
5. Проектирование операционных устройств
6. Потоковые и конвейерные реализации операционных устройств
7. Проектирование устройств хранения информации
